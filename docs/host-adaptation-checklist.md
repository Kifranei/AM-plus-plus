# 宿主版本适配清单

每个精确构建独立使用本清单，包括复用已有页面族的构建。填写结果时区分“已核对”“未确认”“不适用”“已知降级”；不适用须注明 profile 资格或页面族依据。一个版本的结果不能代替另一个版本。

流程和实现边界见 [宿主适配手册](host-adaptation-guide.md)，功能语义和人工场景见 [功能保全与验收矩阵](feature-preservation.md)。单次执行记录保存在任务记录中，本文件作为可重复使用的模板。

## 1. 构建身份与工作范围

| 项目 | 本构建填写内容 |
|---|---|
| 精确身份 | 包名 / versionName / versionCode；二进制 Manifest 来源 |
| 安装包 | 格式、base、split 列表、DEX 和资源所在位置 |
| 代码基线 | 分支或提交、已有未提交工作、可回退代码和产物 |
| 对照宿主 | 对照构建及其页面族；复用的契约和独立分析范围 |
| 档案 | JSON 文件名、id、profileRevision、索引位置 |
| 页面族 | `legacy-activity` / `fragment-content` / 需新建的页面族 |
| 能力边界 | productionEnabled、glass、cellular、staticCollapsedIntercept、playerRecovery 等 |
| 证据范围 | 源码/DEX、资源、静态检查、构建、人工验收分别到哪一步 |
| 执行范围 | 所需源码分析、构建和使用者手动场景；其他检查是否有明确安排 |
| 数据约束 | 配置 schema、键、文件 ID、目录、数据库、缓存、ZIP 和插件接口 |

- [ ] 身份由实际 base Manifest 确认，外层清单和传入参数与其一致。
- [ ] 全部 DEX 与资源 split 已纳入分析，未假定 base 包含所有内容。
- [ ] 正式版、beta、同名不同 versionCode 分别建档。
- [ ] 未把旧混淆类仍然存在视为调用路径未变。
- [ ] profile 使用宿主原始类型与描述符，未复制反编译工具修复的类名、推断类型或冲突文件名。
- [ ] 当前支持构建与参考构建的资格已区分；已有不支持项和降级已记录。
- [ ] 默认不执行设备、功能脚本、全量测试或哈希检查；功能由使用者手动验收。

## 2. 版本数据与解析

### 2.1 profile 完整性

- [ ] 包名、版本名、版本号、文件名和唯一 id 对应同一组合。
- [ ] 页面族来自实际入口和布局，工厂已具备该族的能力实现。
- [ ] indexed、HLE hookTargets、运行时辅助成员和资源均有当前包的依据。
- [ ] 方法填写声明 owner、完整参数/返回类型和 static；字段填写 owner、类型和归属。
- [ ] 构造器、继承成员、接口返回关系、数组和 primitive 分别核对。
- [ ] Hook 目标为可用具体实现；抽象调用契约按需要注明 invocationOnly。
- [ ] 新档案使用 reject-ambiguous，未复制历史首个匹配例外。
- [ ] 旧 HLE 候选条目顺序和兼容语义保持；新 Fragment 契约使用当前精确档案。
- [ ] 开发期生产资格保持未启用；用户测试启用和运行时验收状态分别记录。
- [ ] verification、evidence、knownDegradations 与已取得证据一致。
- [ ] 源码、描述符和资源证据可追溯，引用的文档或位置有效。
- [ ] 索引只登记一次，既有条目的相对顺序保持。

### 2.2 逐成员证据模板

| 功能 / 角色 | 完整成员或资源 | 当前调用来源 / 含义 | 解析与调用决定 | 状态 |
|---|---|---|---|---|
| 待填写 | owner、签名或资源名及限定符 | 调用者、返回对象、原生读写位置 | 精确解析 / 允许的回退 / 调用形式 | 已核对 / 未确认 / 不适用 |

每个直接 Hook 入口继续展开其辅助成员。入口本身匹配不能代替 binding、getter、holder、listener、模型字段或清理方法匹配。

<a id="cjk-animation-checks"></a>

### CJK 辉光与末词扫光检查

实现、精确成员和后续版本维护规则见 [适配手册 7.2](host-adaptation-guide.md#cjk-animation)。

- [ ] 原辉光的单词作用域、前景字段、binding、触发门槛和结束清理按当前构建核对。
- [ ] `cjk.terminalGradient` 的 13 个方法、4 个字段角色与完整描述符有当前包证据；缺少契约时明确记录补偿不适用。
- [ ] 扫光/余量方法参数语义、羽化单位、末词 ID、原文/发音向量与延迟动画标签保持一致。
- [ ] reader 在文档或词序列更新时的替换/复用方式明确，末词缓存不会沿用到新数据。
- [ ] 同一 CJK 开关控制两部分安装；成员缺失或注册失败时新 hook 失活，原辉光保留。
- [ ] 手动观察短尾词全亮、长尾辉光、Latin 原生规则及开关重启；按实际设备、宿主和场景记录。
- [ ] 保留原生逐字时长、词分组、整行切换与位移，不将本项验收扩展为防中断或换行修正通过；跨行遮罩修复属独立能力，见[跨行歌词扫光检查](#lyric-wrap-sweep-checks)。

#### CJK 人工场景

| 场景 | 观察重点 |
|---|---|
| CJK 短尾词 | 最后一个字在原生时间内逐渐全亮，末尾不残留暗边或再次突然补亮 |
| 辉光长尾词 | 末词补偿和原辉光同时正常，原有缩放、回落、结束清理及位移保持 |
| 英文和 Latin 发音 | 保留原生扫光终点及延迟规则 |
| 切歌、循环、拖动进度 | 不把其他 reader 或其他词的末词结果用于当前动画 |
| 开关启停并重启 | 辉光与末词补偿由同一设置控制 |
| 不支持或缺失成员 | 原有辉光保留，补偿的不支持或降级原因可从能力安装信息区分 |

<a id="lyric-wrap-sweep-checks"></a>

### 跨行歌词扫光检查

实现、几何语义、精确成员与后续版本维护规则见 [适配手册 7.3](host-adaptation-guide.md#lyric-wrap-sweep)。本项与 7.2 的 CJK 末词补偿相互独立；CJK 项通过不代表本项通过，反之亦然。

- [ ] 当前精确档案声明顶层 `lyricWrapSweep` 且 `contractVersion = 1`；未声明版本记录不支持并保留原生。
- [ ] 19 个方法角色与 24 个字段角色有当前包完整描述符；类型关系（同 owner、参数类型、View/ViewGroup 归属、listenerMask/fadeMask 类型与 owner、两路暗色 int[]、四路词 Map、mediaBrowser/mediaPosition 返回）逐项核对。
- [ ] 遮罩键确认为视觉行首个 child 索引，不是 TTML lineId、歌词序号或 adapter position；`maskFirst`/`maskLast` 行范围与 `topMasks`/`bottomMasks` bank 归属有当前包依据。
- [ ] 仅 registered 且遮罩身份与方向一致的跨行词动画被接管；同一 flexbox/bank 只保留最新接管；单行、几何不完整和不支持的混合方向复合形状保持原生。
- [ ] 进度使用原生媒体浏览器位置的同一毫秒时间轴；初始及每帧进度由词 begin/duration 与当前位置得出，同一接管内只前进，Seek 后新接管可回退；时长最多缩至剩余段，未新建全局计时器。
- [ ] 延迟单行补亮（rush 动画）只在当前仍持有成功绘制的多行几何、且该几何仍有效时抑制写入；主扫光失败释放接管标记，补亮重新核对几何，失败时原生透传；跨行计划生成的两个羽化 stop 与 `mask.i` 均在片段边界内，末片段完成不提前点亮下一词，交接层仅保留已经实际绘制过的后继边缘。
- [ ] `maskUpdate` 参数确认为 `int[]`、`float[]`、装箱 `Float`；后继主扫光、补亮与静态写入均经该入口。仅已成功完成绘制的跨行遮罩记录交接边界，兼容颜色方向和有序四 stop 才保护，写入成功后才推进记录；保留原版颜色、`mask.i`、动画时长与调度。
- [ ] 跨行长 span → 同行短 span 的完全亮色边缘与渐变前沿连续；两个 stop 分别单调，不能只限制单个 Sweep 的整词进度。LTR/RTL 对称，不提高原版前沿导致短后继余量非正，也不影响无跨行前段的原生单行扫光。
- [ ] 交接保护使用不可变几何快照；宽度、TextView/Layout、文本或遮罩身份失效即释放。暗色/未来 W 在原版写入前清对应 bank，纯暗色遮罩写入、退场、Seek、换绑/回收、文档替换、清空遮罩、布局变化及作用域关闭均清保护。
- [ ] `staticMask`（W）每次先清掉同 flexbox/bank 的旧帧；词为空、未开始、前缀调色板为原生暗色或形状不支持时保留原生。其余已开始的跨行词在存在活动接管时按其最新进度、颜色与羽化重绘，无接管时按当前位置重建；`rebind`（i0）与布局变化后几何失效并按当前状态重绘，羽化随当前宽度重算。
- [ ] 区分未来行初始化与已唱词恢复；缓存重绘前复核词 begin，未开始的词不能因零进度映射而点亮 span 前缀或后续未播放的歌词行。
- [ ] `foregroundInactiveColors`/`backgroundInactiveColors` 与原版 W 的比较语义一致；已唱但不活跃的行不被静态恢复重新点亮。`fadeUpdate`/`fadeMask` 覆盖绕过 W 的退场写入，核对当前遮罩 bank 身份后清缓存并退役旧写入；原版渐暗继续执行，旧遮罩回调不影响新绑定。
- [ ] 入场渐亮的暗色首帧不退役活动扫光；静态帧与布局重绘均遵守原版亮暗状态，退场曲线和调度由宿主控制。
- [ ] `rebind` 核对当前 holder 四路词 Map 的对象身份和文本/Layout 身份；`bind`/`recycle`/`document`/`clearMasks`/`seek` 退役旧回调与静态帧；Seek 取消旧词动画集释放 `word.o`，`pause`/`pauseRequested`/`resume` 同步原生词动画；作用域关闭清理布局监听。
- [ ] 缺少契约或注册失败时能力明确降级，回调异常只记录一次同类原因并保持原生透传。
- [ ] 结果按具体版本、设备和场景记录；未执行保持待验收，静态成员匹配或构建成功不等于真机通过。

#### 跨行歌词扫光人工场景

| 场景 | 观察重点 |
|---|---|
| 两行跨行词 | 高亮按实际字形宽度跨两行连续推进，行首/行尾无暗边残留，第二行不落后也不提前 |
| 从头播放且未来行可见 | 未到时间的行始终保持原生暗色，包括未来行的最后一个 span 跨视觉行、span 前存在其他词的情况；预加载、重新绑定与布局刷新不会提前高亮 |
| 已唱行退场及重新显示 | 原生渐暗连续执行，退场后布局刷新或重新绑定不恢复旧亮色；过期遮罩的渐暗回调不撤销新行接管 |
| 当前行入场渐亮 | 暗色首帧不提前结束活动扫光，亮度曲线继续使用原版动画 |
| 三行跨行词 | 累计宽度按文本顺序推进；末行完成时整词全亮，无补亮覆盖 |
| 跨行长 span → 同行短 span | 上一段尾部已亮文字不被下一段羽化重新画暗，后一段仍按原版时间扫光；手机/平板改变视觉行数后交接仍连续 |
| 后继补亮或静态刷新 | 兼容方向的两个 stop 不回撤，原版颜色变化继续；原几何无效或暗色状态不沿用旧亮边 |
| 原生单行 span、不同遮罩或相反方向 | 没有已完成跨行遮罩保护的写入保持原生，不按固定字数、歌词内容或设备种类特判 |
| 词内中段 Seek（之前 / 之后） | Seek 后按新的当前位置重建进度；旧接管不写入新位置 |
| 暂停 / 恢复 | 原生动画随播放暂停与恢复；恢复后进度连续，无跳变重复刷新 |
| 切歌 / 行回收 | 换绑与回收后旧回调不写入新行；新行按自身状态从头推进 |
| 字体或字号变化、旋转、双栏 | 布局重建后按新几何继续；旧几何失效，不沿用旧宽度；扫光期间或末尾无法接管时原生补亮可继续写入 |
| 原文（TOP）与发音（BOTTOM）词 | 同一 flexbox 内只接管该词所在 bank；另一 bank 保持原生 |
| 前景与背景词 | 前景与背景是两个独立 flexbox，各自独立接管或保持原生；不能把 TOP/BOTTOM 当作前景/背景 |
| RTL 歌词 | 渐变方向与行内推进方向与文字方向一致 |
| 混合 Bidi 或复合形状 | 明确不支持时保持原生渲染，能力状态可区分 |
| 关闭 CJK 辉光 / 未声明契约的版本 | 跨行修复独立于 CJK 开关；未声明契约时报告不支持并保留原生 |

### 歌词模糊检查

显示规则、状态分层、独立契约、效果所有权与诊断见 [适配手册 7.1](host-adaptation-guide.md#lyrics-blur)。

- [ ] 必需角色、profile 和离线维护清单同步，模糊资格不依赖双栏。
- [ ] 完整 owner、类型和接口关系有当前包证据；原生 ID 与 adapter 稳定 ID 角色分开。
- [ ] 已应用快照与 raw 事件分开，核对子集保留、列表动画等待和 Handler 提交。
- [ ] 行 ID、歌词序号、列表位置分开，绑定代际和 holder 身份可校验。
- [ ] 四路文字动画与装饰分开，辉光/位移不延长保护，文字结束/取消与 Seek 清理完整。
- [ ] 首句/末尾时间、播放位置和三点实际显示状态可读；延迟三点可切换，真实高亮优先，结尾保留有效焦点。
- [ ] 每个 root 独立会话，暂停打开有首帧，同 wrapper 文档重装更新代际。
- [ ] 用户浏览、惯性和程序滚动区分，1秒恢复任务校验代际。
- [ ] 逻辑行动画、换绑、边缘变换、效果所有权和整组失败释放有明确路径。

#### 歌词模糊人工场景

| 场景 | 验收标准 |
|---|---|
| 逐行首句、三点消失 | 首句连续渐清，不上下错行；区分目标 0 与 300ms 内的实际非零半径 |
| 无三点前奏、暂停打开 | 文档首句清晰，后续原曲线模糊，首帧不依赖下一次播放 |

| 拖动、长按、惯性、程序滚动 | 浏览持续解除焦点模糊，结束 1 秒后恢复；自动跟随不误入浏览 |

| 平板边缘、缩放与位移 | 边缘随当前几何和 padding 更新，高亮渐清连续 |
